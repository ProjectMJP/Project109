# Git Commit & Push 자동화 가이드

본 스킬이 활성화되면 에이전트는 다음 프로세스를 순차적으로 수행한다.

## [프로세스 단계]

### 0단계: 워킹 트리 상태 점검 및 원격 동기화
1. `git status`를 실행하여 워킹 트리가 깨끗한지(clean) 확인한다.
2. 로컬에 미커밋된 변경사항이 없다면 원격 최신 변경 내용을 반영하기 위해 `git fetch` 및 현재 브랜치의 `git pull`을 실행하여 로컬 브랜치를 최신화한다.
3. 만약 로컬에 이미 수정 중인 파일이 있다면 임의로 pull을 강행하지 말고, 로컬 작업 분석 및 커밋 분할(1단계)로 직행한다.

### 1단계: 변경 사항 분석, 대화 맥락 추론 및 커밋 분할 제안
- 현재 작업 디렉토리의 변경된 파일 목록(`git status`)과 변경 내용(`git diff`)을 파악한다.
- **대화 내역(Context) 기반 분석:** 단순 코드 변경점 외에 사용자와 나눈 대화 맥락(문제 제기 배경, 리팩토링 및 설계 방향, 아키텍처 결정 사항)을 종합하여 변경의 본질적인 목적을 추론한다.
- **원자적 커밋 분할 (Atomic Commits):** 변경 사항이 기능 추가(feat), 구조 개선(refactor), 버그 수정(fix), 도구/설정(chore) 등 서로 다른 성격이거나 별개 모듈 단위로 나뉠 수 있다면, 단일 커밋으로 묶지 않고 2개 이상의 독립적인 커밋으로 분할하여 제안한다.
- 사용자가 지시하지 않은 변경 사항이나 불필요한 임시 파일들은 커밋 대상에서 제외한다.
- `.agents/rules/git-commit-rule.md`에 정의된 커밋 메시지 컨벤션을 적용하여 각 커밋별로 명확한 제목과 상세 본문을 생성한다.
- **실행 전 사용자에게 컨펌을 받는다:**
  > "다음 변경 사항에 대해 [N]개의 커밋으로 분할하여 진행할까요?
  >
  > [커밋 1]
  > - **메시지:** ...
  > - **대상 파일:** ...
  >
  > [커밋 2]
  > - **메시지:** ...
  > - **대상 파일:** ..."

### 2단계: 커밋 및 원격 반영 실행 (컨펌 이후 실행)
사용자의 승인이 완료되면, 실행 가능한 방식을 선택하여 원격지에 반영한다. (로컬 히스토리 동기화를 위해 **방법 A(로컬 명령어)를 우선적으로 사용**한다.)

#### [방법 A] 로컬 Git CLI 명령어 사용 (권장)
1. 사용자가 승인한 변경 파일들만 스테이징 영역에 추가한다.
   - `git add <지정한 파일 목록>`
2. 1단계에서 승인받은 커밋 메시지를 적용하여 로컬 커밋을 생성한다.
   - **[PowerShell 환경 주의]**: 윈도우 PowerShell 환경에서는 `-m` 옵션을 여러 개 분할 호출할 경우 문단 사이에 이중 개행(빈 줄)이 자동 삽입된다. 따라서 반드시 제목과 본문 전체를 단일 `-m` 옵션의 큰따옴표("") 내에 줄바꿈을 직접 포함시켜 호출해야 한다.
   - `git commit -m "<승인된 커밋 메시지 전체>"`
3. 사용자가 명시적으로 푸시를 요청하거나 허용한 경우에만 현재 활성화된 로컬 브랜치명을 기반으로 푸시한다. (단, 사용자가 푸시 보류를 요청했거나 main/master 브랜치인 경우 제외)
   - `git push origin <현재 브랜치명>`

#### [방법 B] GitHub MCP 도구 사용 (방법 A가 실패하거나 로컬 CLI 실행 권한/인증이 없는 경우)
1. 연결된 GitHub MCP 서버의 `get_status` 또는 이에 준하는 도구로 스테이징 상태를 확인한다.
2. `create_commit` (또는 `push_files`) 도구를 호출하여 변경 내용을 커밋 및 푸시한다.
   - 이때 1단계에서 승인받은 커밋 메시지를 파라미터로 넘긴다.

#### [추가 자동화] GitHub 연동 작업 (사용자 요청 시)
- 푸시가 완료된 후 Pull Request(PR) 생성이 필요한 경우, GitHub MCP의 `create_pull_request`를 호출하여 PR 작성을 자동화한다.

### 3단계: 결과 보고
- 커밋 및 푸시가 완료되면 커밋 해시와 변경 내역 요약을 사용자에게 안내하고 스킬을 종료한다.
